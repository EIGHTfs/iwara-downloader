> 本方案仅为设计草案，未实际修改任何代码。请审核确认后，再按方案执行。
> 分四次写：① 取消点赞/取关（已完成）｜② 搜索列表点赞字段 + mtime 刷新（已完成）｜③ 播放器滑动音量与进度（已完成）｜④ 进度条图片预览（本文档）

## 一、修改目标

- **问题描述**：播放页进度条拖动时无画面预览——不知道拖到哪一帧。ArtPlayer 官方支持 `thumbnails` 配置（进度条 hover 显示对应时间点的预览图），且本服务**已有完整抽帧管线**（`server/lib/thumb-cache.cjs` `extractFrame` + `findFfmpeg` 定位项目 `tool/ffmpeg`），只差把「单帧封面」扩展成「N 帧雪碧图」。
- **期望效果**：
  1. 播放页进度条 hover/拖动时，进度条上方显示当前时间点的视频预览图（B 站式）
  2. 预览图为**本地生成**（不依赖官方接口）：用 ffmpeg 按视频时长均匀抽 N 帧 → 拼一张横向 sprite 雪碧图 → 缓存到 `server/thumbs/<id>-sprite.jpg`
  3. 已有视频**首次进入播放页触发生成**（或后台 warmup 顺带生成），生成中不阻塞播放（预览图没有时进度条照常，hover 无图不报错）
  4. N 按视频时长自适应（短片少帧、长片多帧，如 5~16 帧），sprite 单张大小可控（每帧 160 宽，总宽 N×160，最大约 2560px）
- **成功标准**：
  1. `GET /api/thumbs-sprite?id=<vid>` 返回 sprite 图（200，image/jpeg），无图时 404
  2. `play-info` 或独立接口返回 sprite 元信息（`{ url, number, column, width, height, duration }`），前端配置进 ArtPlayer `thumbnails`
  3. 进度条 hover 显示预览图且位置随播放进度正确（ArtPlayer 官方行为：`number`=总帧数、`column`=每行帧数，宽高=每帧像素）
  4. 拖动进度时预览图跟随
  5. 视频下完/首次播放后 sprite 生成，播放页刷新后有预览；生成中无预览不报错（控制台无异常）

## 二、潜在问题分析

| 风险类型 | 可能性 | 影响 | 缓解措施 |
|----------|--------|------|----------|
| sprite 生成耗时/资源 | 中 | 抽 N 帧拼图（长视频 N=16 约需 1~3s ffmpeg 时间、~100MB 内存） | 后台队列生成（复用现有 inflight 模式），并发 1；生成中不阻塞播放；只对完整视频生成（partial 跳过） |
| URL/时间对应漂移 | 中 | sprite 帧时间戳与 ArtPlayer 期望的均匀分布不匹配 | 抽帧时间点 = `总时长 / N × (i + 0.5)`；`thumbnails.url` 直接指向稳定 URL，ArtPlayer 按 `number/column/width/height` 自行映射（均匀分布假设与生成一致） |
| 部分下载视频 | 高 | `.part` 未下完，时长不准/抽帧抽到无效区域 | `partial` 视频不生成 sprite（进度条预览只对完整文件）；`info.partial` 时跳过 |
| sprite 文件命名冲突 | 低 | `<id>-sprite.jpg` 与现有 `<id>.jpg` 封面并存 | 独立命名 + 独立接口，不碰现有 `thumbs/<id>.jpg` 封面逻辑 |
| 无 ffmpeg 环境 | 中 | 生成失败 | `findFfmpeg()` 兜底返回空 → 接口 404、前端无预览（优雅降级，同现有封面行为） |
| 缩略图尺寸过大 | 低 | 长视频 16 帧 sprite 像素高 | 每帧 160 宽 + `-q:v 5`，单图 <300KB；N 上限 16 |

**边界条件**：
1. 无视频文件 / partial：sprite 不生成，接口 404，前端 `thumbnails` 不配置 → ArtPlayer 不显示预览（不报错）
2. 视频时长 <= 5s：N=1（单帧），column=1
3. sprite 已存在：直接返回（mtime 缓存，不做热失效；视频文件变更后由 warmup/ensure 覆盖——本次不做监听，可入后续清单）
4. 并发多个视频同时打开：生成队列串行（`inflight` Map 复用）

## 五、逐文件改动详情

### 5.1 `server/lib/thumb-cache.cjs`

- **当前位置**：`extractFrame` :103-145（单帧）；`inflight` :18；`THUMB_DIR` :17
- **改动内容**：
  1. 新增 `spritePath(id)`：`THUMB_DIR/<id>-sprite.jpg`；`spriteExists(id)`（jpg 校验同 `hasThumb`）+ `readSprite(id)`
  2. 新增 `extractSprite(videoPath, outPath, duration, opts)`：
     - `opts.n` 帧数（`clamp(round(duration/30), 4, 16)`，`duration<=5` 时 n=1）
     - ffmpeg 一次输出：`-i video -vf "scale=160:-2,fps=1/每帧间隔" -frames:v N -q:v 5 out-%d.jpg`；
       或用 `-filter_complex "tile=Nx1"` 一步拼 sprite（优先，少中间文件）——实现时按 ffmpeg 版本实测 `tile` 是否可用，不行退回逐帧+本地拼接（`concat` 二进制拼接 jpg 不可行，需用 `-i out-1.jpg ... -filter_complex hstack` 或直接 ffmpeg tile）
     - 与 `extractFrame` 同款：20s 超时、`SIGKILL`、`tmp` + rename、失败清理
  3. 新增 `generateSprite(id, videoPath, duration)`：`inflight` 去重 + `spriteExists` 短路 + 后台 Promise（供路由触发 & 播放页请求时顺手生成）
  4. 导出新增三函数
- **改动原因**：进度条预览图数据源
- **潜在影响**：无（新函数，不改现有封面逻辑）；`THUMB_DIR` 多一类 `<id>-sprite.jpg`（`listCached`/`pruneUnknownThumbs` 按 `.jpg` 结尾会扫到 sprite！**必须过滤** `-sprite.jpg` 后缀，避免把 sprite 当封面 id 处理——见 5.4 风险）

### 5.2 `server/routes/play.js`

- **新增路由** `GET /api/thumbs-sprite?id=`：`readSprite` 有则返回 image/jpeg；无则 404
- **`play-info` 响应**：`hasFile && !partial` 时尝试 `readSprite`（已生成）→ `sprite: { url: "/api/thumbs-sprite?id=", number, column: number(横排单行), width: 160, height: <按视频比例> }`；未生成则**后台触发 `generateSprite`** 并返回 `sprite: null`（下次刷新有）
- **改动原因**：前端拿 sprite 元信息

### 5.3 `server/public/play-app.js`

- **改动内容**：`artOptions(info, poster)` 里若 `info.sprite` 存在 → `thumbnails: { url: info.sprite.url + "&v=" + sprite版本号, number: info.sprite.number, column: info.sprite.column, width: info.sprite.width, height: info.sprite.height }`（加 vid 时间戳防缓存：`&v=<mtime>` 或直接用 URL 内联 vid）
- **改动原因**：ArtPlayer 进度条预览
- **潜在影响**：低。ArtPlayer 无 thumbnails 配置时不显示预览（回归确认）

### 5.4 已知坑（先记录）

- `listCached` :312 过滤条件要加 `!n.endsWith("-sprite.jpg")`，否则 warmup 的 `pruneUnknownThumbs` 会把 sprite 当封面 id 或误删
- `video-index` / thumbs 目录扫描若按 `.jpg` 前缀匹配 id，sprite 命名 `<id>-sprite.jpg` 不会撞（`<id>` 正则 `[A-Za-z0-9_-]{4,64}` 不含 `-` 后的 sprite 冲突）
- sprite 生成用 `tile` 时注意方向：`tile=Nx1` 横向；ArtPlayer `column` = 每行帧数（=N），`number` = 总帧数（=N），单行 sprite
