# 视频页

播放页（地址形如 `/{视频ID}`）的完整实现：页面加载、播放器配置、画面手势、播放列表。

## 一、文件分工

| 文件 | 职责 |
| --- | --- |
| `server/public/play.html` | 页面骨架：播放器容器、标题/作者/标签区、点赞关注按钮、播放列表容器、排序控件 |
| `server/public/play-app.js` | 主控：ID 解析与地址规范化、播放器初始化、元信息渲染、状态按钮、切换视频、错误提示 |
| `server/public/play-enhance.js` | 交互增强：倍速按钮、点击即播、菜单抑制、长按快进、画面横滑 scrub seek、竖滑音量、进度条触摸滑动 |
| `server/public/play-list.js` | 播放列表：排序维度/方向、文件夹分组与折叠、自动连播、偏好持久化、增量加载 |
| `server/public/vendor/artplayer.js` | 播放器内核（本地静态文件，零 npm 依赖） |
| `server/public/vendor/artplayer-plugin-vtt-thumbnail.js` | 进度条缩略图预览插件（本地静态文件） |
| `server/routes/play.js` | 播放流、播放信息、缩略图接口、头像 |
| `server/lib/thumb-cache.cjs` | 封面缓存与缩略图雪碧图生成 |

脚本加载顺序（顺序有依赖）：

```
theme-init.js → vendor/artplayer.js → vendor/artplayer-plugin-vtt-thumbnail.js
→ play-list.js → play-enhance.js → play-app.js
```

`play-list.js` 与 `play-enhance.js` 只定义函数，运行时才引用 `play-app.js` 的顶层全局，因此先加载不报错；`play-app.js` 末尾自行执行入口。

## 二、页面加载链路

### 2.1 请求到 HTML

1. 浏览器请求 `/{视频ID}`（也支持 `/play?id=xxx`、`/play#xxx`）。
2. 服务端按片段拼装 `play.html`：`@frag:名称` 展开为片段内容，`@brand:键` 替换品牌值。
3. 拼装时对页面内本地脚本与样式追加内容指纹（`?v=<内容哈希前 8 位>`），内容一变地址即变。
4. HTML 响应头 `Cache-Control: no-cache`；静态资源按 `max-age` 缓存，但地址已带指纹，改动不会读到旧文件。

### 2.2 前端初始化时序

```
脚本加载完成
  └─ play-app.js 入口
       ├─ 解析 ID：路径段 → hash → query（都没有则取索引里最新一条并跳转）
       ├─ setPlayUrl(id)：地址规范化为 /{视频ID}（replaceState，不产生历史记录）
       ├─ initTheme()：恢复夜间/白天模式与按钮文案
       ├─ bindStateButtons()：绑定点赞/关注点击
       └─ loadVideo(id)
            ├─ fetch /api/play-info?id=...
            ├─ renderVideoMeta(j)：标题、时长、标签、附加信息
            ├─ renderAuthor(j)：作者名 + 头像（缺失时按需重试）
            ├─ refreshVideoState(id)：拉取已赞/已关注初始态
            ├─ initPlayer(j, thumbUrl(id))
            └─ renderPlaylist(true)：首次整表渲染列表
```

切换视频（点击列表项 / 浏览器前进后退 / 自动连播）走 `loadVideo(newId)`：销毁旧实例、重新拉播放信息、重建播放器，列表保持已有状态不重绘。

### 2.3 播放器初始化

1. `info.hasFile` 为假 → 显示提示（未下载完成 / 无文件）并返回，不创建播放器。
2. 已有实例先 `art.destroy(false)`（保留容器），避免多实例叠加。
3. `new Artplayer(artOptions(info, poster))`，实例挂到 `window.__art` 便于排查。
4. 移除 video 元素的 `crossorigin` 属性（同源播放无需 CORS 协商，保留反而可能播不了）。
5. 调用 `enhancePlayer(art)` 注入交互增强（失败不影响播放）。
6. 若 `info.thumbVtt` 非空，在 `art.once("ready")` 后注册缩略图插件。
7. 绑定 `error`（错误文案）、`video:ended`（自动连播）、`video:seeking`（边下边播时限制 seek 上限）。

## 三、播放器配置

| 配置 | 值 | 说明 |
| --- | --- | --- |
| `url` | `/api/play?id=<ID>` | 流式接口，支持 Range 与边下边播 |
| `type` | 由文件扩展名推导 | 缺省 `mp4` |
| `poster` | `/api/thumb?id=<ID>` | 封面用稳定地址（不加时间戳），避免刚更新的封面被旧图覆盖 |
| `theme` | 跟随当前主题色 | 与夜间/白天模式一致 |
| `volume` | `0.7` | 初始音量 |
| `autoplay` | `true` | 被浏览器策略拦截时由「点击即播」兜底 |
| `playsInline` | `true` | 移动端内联播放，不强制全屏 |
| `gesture` | `true` | 官方手势保留（进度条区域），画面手势由增强层接管，区域不冲突 |
| `fastForward` | `true` | 移动端长按走官方快进，避免自绘长按双份触发 |
| `setting` / `hotkey` / `pip` / `fullscreen` / `fullscreenWeb` / `screenshot` / `aspectRatio` / `playbackRate` | 开启 | 保留官方控制面板能力 |
| `miniProgressBar` | `true` | 全屏时顶部细进度条 |
| `autoSize` / `autoMini` | `false` | 关闭自动尺寸与自动迷你，避免布局抖动 |

控制条自动隐藏时间延长到 8 秒（`Artplayer.CONTROL_HIDE_TIME = 8000`）：默认 3 秒太短，容易让人以为页面没有进度条。

## 四、画面手势

`enhancePlayer(art)` 为每个播放器实例创建独立的共享状态对象，再依次装配七个模块。模块之间通过该状态对象互斥。

### 4.1 倍速按钮

- 控制条右侧新增按钮，文案 `1x / 1.25x / 1.5x / 2x / 3x`。
- 点击按顺序循环切换 `playbackRate` 并提示当前倍速。
- 监听 `video:ratechange` 与 `video:play` 同步按钮文案（设置面板或快捷键改速时也一致）。

### 4.2 点击即播

浏览器拦截有声自动播放时，页面会停在暂停态。处理方式：

- 初始化 800ms 后若仍处于暂停且未在播放，则武装「点击即播」。
- 武装状态下按下画面：立即播放，并拦截随之而来的 click（否则刚播放又被「单击暂停」停掉）。
- 与长按互斥：长按要求处于播放中，两者不会互相抢占。

### 4.3 菜单抑制

- 按住画面期间拦截 `contextmenu`（捕获阶段），阻断播放器自带的右键面板。
- 松开后延迟 250ms 解除（长按松手瞬间仍可能触发）。
- 右键（`button === 2`）不在拦截范围，桌面右键菜单保留。

### 4.4 长按快进（桌面）

- 按住画面 600ms 且正在播放 → 倍速切到 3x，提示「3x 快进中，松开恢复」。
- 松开/取消/移出画面 → 恢复按下前的倍速，并短暂拦截点击，防止误触发暂停。
- 移动端不装配此模块，长按走播放器官方快进，避免两套快进同时生效。
- 暴露「取消长按计时」的入口供拖动模块调用：一旦判定为拖动立即取消，避免拖动超过 600ms 被误判成长按。

### 4.5 横滑 scrub seek（1 秒粒度）

按住画面左右拖动时，进度条与时间显示实时跟随手指，画面实时跳到对应帧，seek 粒度取整到整秒。

| 阶段 | 行为 |
| --- | --- |
| `pointerdown` | 记录起点、当前时间、总时长、画面宽度；设置指针捕获（拖出画面仍能收到事件）；控制条区域不触发 |
| `pointermove`（画面） | 水平位移超过 10px 判定进入拖动，同时取消长按计时 |
| `pointermove`（文档级） | 按位移比例换算目标时间，`Math.round` 取整到整秒；同一秒内不重复 seek；赋值给播放器当前时间 → 进度条/时间自动更新、画面切到目标帧 |
| 播放中拖动 | 首次进入拖动时记录「原本在播」，随后暂停（连续 seek 会反复触发缓冲造成抖动）；原本暂停则保持暂停 |
| `pointerup` | 定格到松手位置的整秒；原本在播则恢复播放 |
| `pointercancel` / 离开画面 | 清空拖动状态（已进入拖动时不打断） |

目标时间钳制在 `[0, 时长 - 0.1]`。

### 4.6 竖滑音量

- 方向分发：首个位移超过 12px 时锁定方向，`|dy| > |dx|` 判为竖滑（本模块），否则判为横滑（交给 4.5），锁定后不切换。
- 音量计算：`delta = -dy / (画面高度 / 2)`，上滑增大；结果钳制在 `0..1`，同时写 video 元素与播放器的音量属性（图标与控制条同步）。
- 音量大于 0 时自动解除静音；每步提示「音量 N%」。
- 通道：桌面走 pointer；触摸端额外绑定 touch 通道兜底（个别环境 pointer 事件不完整），竖滑时阻止页面滚动。
- 控制条区域与锁定状态不触发。

### 4.7 进度条触摸滑动

官方进度条拖动只绑定鼠标事件，触摸屏上默认 `touch-action` 会把滑动当成页面滚动接管，表现为「点击可以、滑动没反应」。

实现：给官方进度条设 `touch-action: none`，补充 pointer 通道（仅非鼠标指针介入）——按下即跳、按住滑动连续 seek、指针捕获保证拖出进度条不丢尾段；鼠标仍走官方逻辑，互不干扰。

### 4.8 手势互斥

| 场景 | 判定 | 结果 |
| --- | --- | --- |
| 按住 < 600ms 松开 | 未超位移阈值 | 点击（暂停/播放，或触发点击即播） |
| 按住 > 600ms 且播放中 | 未超位移阈值 | 长按 3x 快进（桌面） |
| 首个位移 > 12px 且 `\|dx\| > \|dy\|` | 横滑 | 进入 scrub seek，取消长按计时 |
| 首个位移 > 12px 且 `\|dy\| > \|dx\|` | 竖滑 | 调节音量，取消长按计时与点击即播 |
| 拖动中继续位移 | 已锁定方向 | 不切换模式，持续生效 |
| 拖出画面 | 已进入拖动 | 继续跟随（文档级监听 + 指针捕获） |

## 五、播放列表

### 5.1 数据与排序

- 数据源：`/api/index` 返回的视频映射，转换为 `{ id, title, name, duration, fileId, createdAt, rel }`。
- 排序维度：`time`（按创建时间）或 `name`（按标题，中文排序）。
- 排序方向：`desc`（默认）/ `asc`。
- 偏好持久化：浏览器本地存储三个键——排序维度、排序方向、自动连播开关。

### 5.2 分组与折叠

- 按相对目录分组，每组渲染组标题与组体，组标题可折叠并显示组内数量；根目录显示为「根目录」。
- 组头缓存挂在模块级变量，增量加载时复用，避免重复追加同名组头。

### 5.3 增量加载

- 每次渲染 20 条，滚动到底部继续追加。
- 排序切换或数据变化时整表重绘；单纯追加时不清空容器。

### 5.4 自动连播

- 开关状态持久化（默认开）。
- 播放结束时按当前排序取下一个视频：更新地址（replaceState）→ 重新加载播放器；列表末尾播完则停止。

## 六、边界与取舍

1. **边下边播**：`partial` 为真时进度条只覆盖已写入部分，拖到未写入区域会回落到已缓存位置；页面给出提示，并把超出尾部的 seek 拉回。
2. **封面地址稳定**：封面统一用 `/api/thumb?id=<ID>`，不追加时间戳。历史实现曾用时间戳强制刷新，结果把刚更新的封面立刻换回旧图，且刷新后行为不一致。
3. **拖动期间暂停**：播放中拖动先暂停，避免连续 seek 反复缓冲；松手按原状态恢复，不改变播放意图。
4. **seek 粒度取整到秒**：同一秒内不重复 seek，既降低 seek 频率，也符合「1 秒为最小单位」的定位精度。
5. **触摸双通道**：pointer 为主通道，touch 仅兜底；两通道共用同一套状态，以先锁定方向者为准。
6. **移动端长按**：用官方快进，自绘长按仅桌面启用。

## 七、验证方法

- 静态检查：`node --check` 覆盖 `play-app.js`、`play-enhance.js`、`play-list.js`。
- 页面结构：确认脚本加载顺序正确、资源带内容指纹。
- 桌面手势：横拖观察进度条时间实时变化与画面逐秒跳帧、松手恢复播放；竖滑观察音量提示与图标同步；长按 600ms 观察 3x 与松开恢复。
- 触摸端：真机验证横拖、竖滑、进度条滑动三条通道均不被页面滚动接管。
- 列表：切换排序与方向后刷新，偏好应保留；播放到末尾应自动切下一个（开关关闭时不切）。
