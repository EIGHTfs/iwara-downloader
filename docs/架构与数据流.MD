# 架构与数据流

## 一个进程，两种角色

`node server/boot.cjs` 起一个 HTTP 服务，同一个端口既服务页面也服务 API：

```
浏览器 ──┬─→ GET /             → 页面（由若干片段拼装）
         ├─→ GET /api/...      → JSON 数据
         ├─→ GET /api/play     → 视频字节流（支持 Range）
         └─→ GET /{视频ID}     → 播放页
```

没有额外的静态服务器，没有数据库；所有持久化都是项目内的 JSON / JSONL 文件与媒体文件。

## 请求怎么走

```
HTTP 请求
  → 鉴权层（页面需要访问密码；只读类接口按配置放行）
  → 路由分发（按路径 + 方法）
  → 业务处理
      · 数据类：读索引 / 缓存 → 合并本地状态 → 返回 JSON
      · 媒体类：定位本地文件 → 直接输出字节流（支持 Range 与边下边播）
      · 操作类：调用远端接口 → 更新本地状态文件 → 返回结果
  → 响应
```

页面请求与接口请求共用同一套鉴权：页面未登录会被重定向到登录页，接口未登录返回 401（放行的接口除外）。

## 数据落在哪

| 路径 | 内容 | 可否删除 |
| --- | --- | --- |
| `server/config.json` | 端口、凭证、下载路径、文件名规则、后端选择、密码 | 不建议，删除后需重新配置 |
| `json/download_task.json` | 下载任务进度 | 可删，任务列表会清空 |
| `json/cdn_hosts_state.json` | CDN 子域的成功/失败记录 | 可删，会重新探测 |
| `json/search_cache.json` / `json/search_task.json` | 搜索缓存与按时间搜索任务 | 可删，会重新搜索 |
| `json/liked_state.json` | 本地已赞 / 已关注状态 | 可删，会重新同步 |
| `json/following_cache.json` | 关注列表增量缓存 | 可删，会重新拉取 |
| `json/profile/` | 作者信息索引 | 可删，会按需重建 |
| `server/thumbs/` | 封面与缩略图雪碧图 | 可删，会按需生成 |
| `avatar/<作者ID>/` | 作者头像 | 可删，会按需下载 |
| `server/server.log` | 运行日志 | 可删 |
| 下载目录（`downloadPath`） | 视频文件 | 不可删，是用户内容 |

## 前端组织

页面是单个 HTML + 若干静态脚本与样式，无构建步骤：

```
server/public/
  index.html        下载 / 进度 / 搜索 / 设置 四个选项卡
  play.html         播放页
  app.js            主页面业务脚本
  play-app.js       播放页业务脚本
  play-enhance.js   播放页交互增强（手势、倍速、长按）
  play-list.js      播放页播放列表
  style.css         样式
  fragments/        HTML 片段与样式分片
  vendor/           本地化的第三方播放器与插件
```

页面 HTML 由片段拼装生成：`@frag:名称` 展开为片段内容，`@brand:键` 替换为品牌值。拼装时对页面内的本地脚本与样式自动追加内容指纹（`?v=<内容哈希前 8 位>`），文件内容一变 URL 即变，浏览器不会继续使用旧文件。

## 端口与访问

服务监听端口由 `server/config.json` 的 `port` 决定（默认 8643）。局域网内用 `http://<NAS-IP>:<端口>/` 访问即可，不需要额外开放路径。

## 关键设计取舍

- **零依赖**：不引入 npm 依赖，启动器 `server/boot.cjs` 强制本项目 `.js` 按 CommonJS 加载（父目录若声明 ES Module 也不会影响）。
- **文件即数据库**：任务、缓存、状态都是 JSON/JSONL；写入采用原子替换，避免半写坏文件。
- **本地状态优先**：远端接口可能返回过期或不完整的状态（例如列表接口对已赞标记恒为 false），因此点赞/关注等状态以本地状态文件为准，远端只作校验。
- **媒体流直出**：视频与封面不走内存缓冲，边读边发；未下完的文件按已写入字节提供 Range。
