# 进度条缩略图

进度条悬停（桌面）或拖动（触摸屏）时显示对应时间点的画面缩略图。

## 一、方案与取舍

| 方案 | 结论 | 原因 |
| --- | --- | --- |
| 播放器官方 `thumbnails` 配置 | 不采用 | 只能在初始化时注入，运行期无法追加；且需要自行准备雪碧图与描述文件 |
| 浏览器端自动抽帧插件 | 不采用 | 大文件在浏览器里 seek 慢，且跨域场景受限 |
| **服务端生成雪碧图 + VTT，前端用插件读取** | 采用 | 生成一次长期复用；前端只读静态文件，零额外计算 |

前端插件选用官方 VTT 缩略图插件，以本地静态文件形式放在 `server/public/vendor/`，不引入 npm 依赖。

## 二、前端接入

- 触发条件：播放信息接口返回的 `thumbVtt` 非空（完整文件、非边下边播、时长大于 0）。
- 注册时机：播放器 `ready` 事件后注册插件——播放器不支持初始化后修改缩略图配置，插件化注册天然规避该限制。
- 插件行为：监听播放器进度条事件，在进度条上方显示对应时间的帧图（按 VTT 里的 `#xywh` 从雪碧图裁切）；触摸屏在拖动进度条时同样显示。
- 未生成或生成中：接口返回 404，前端不注册插件，页面无报错。

## 三、服务端生成

### 3.1 参数

| 参数 | 规则 |
| --- | --- |
| 帧数 `N` | 时长 ≤ 5 秒取 1；否则 `clamp(round(时长 / 30), 4, 16)` |
| 列数 `col` | `min(4, ceil(sqrt(N)))` |
| 行数 `row` | `ceil(N / col)` |
| 帧宽 `w` | 固定 160 |
| 帧高 `h` | 按原视频宽高比换算并向下取偶（满足 yuv420 要求） |
| 每帧时长 | `时长 / N` |

### 3.2 生成流程（两段式）

第一段：按 N 个时间点分别抽单帧——输入 seek 到目标时间、只解一帧、缩放到目标宽、输出 JPEG。并发 2，单次 30 秒超时。

第二段：把 N 张帧图作为多输入，用 `concat` 拼接后 `tile` 成 `col × row` 的拼图，输出一张雪碧图。

> 早期实现用「按间隔取帧」的滤镜一次性抽帧，需要整片解码，长视频会超时（实测 10 分钟视频超过 60 秒被终止）。改为输入 seek 后单帧耗时降到 0.2~0.3 秒，总耗时与视频长度基本无关。

### 3.3 输出

| 文件 | 内容 |
| --- | --- |
| `server/thumbs/<ID>-thumb.jpg` | 雪碧图 |
| `server/thumbs/<ID>-thumb.vtt` | WebVTT 描述 |

VTT 结构：

```
WEBVTT

00:00:00.000 --> 00:00:40.188
/api/thumbnail-sprite?id=<ID>#xywh=0,0,160,90

00:00:40.188 --> 00:01:20.375
/api/thumbnail-sprite?id=<ID>#xywh=160,0,160,90
```

时间与坐标由同一组参数生成：帧 `i` 的起始时间为 `i × 每帧时长`，坐标 `x = (i % col) × w`、`y = floor(i / col) × h`，与实际拼图布局严格一致，不会出现「显示错帧」。

### 3.4 触发与去重

- 播放信息接口在返回 `thumbVtt` 的同时后台触发生成，不阻塞响应。
- 生成过程按视频 ID 去重：同一视频的并发请求只跑一次；已存在则直接短路。
- 临时帧文件写在独立目录，结束后清理。

## 四、接口

| 接口 | 说明 |
| --- | --- |
| `GET /api/thumbnail-sprite?id=<ID>` | 返回雪碧图 JPEG；未生成 404；命中缓存一天 |
| `GET /api/thumbnail-vtt?id=<ID>` | 返回 VTT 文本；未生成 404 |

封面索引只收集 `.jpg` 且排除 `-thumb.jpg` 与临时文件，因此雪碧图与 VTT 不会被误当成封面读取或清理。

## 五、边界

1. **边下边播不生成**：文件未下完时时长不准、抽帧区域可能无效，`partial` 为真时不生成也不注册插件。
2. **极短视频**：≤ 5 秒只生成 1 帧，列数 1。
3. **雪碧图不随视频变更自动失效**：视频文件被替换后需要手动删除旧图（当前不做文件监听）。
4. **帧密度上限**：最多 16 帧，长视频每帧覆盖区间较大（例如 10 分钟视频约 40 秒一帧），预览精度受此限制。
5. **工具缺失降级**：找不到 ffmpeg 时不生成、接口 404、前端不注册，播放不受影响。
6. **可执行位**：随包提供的 ffmpeg/ffprobe 包装脚本必须保留执行位，否则抽帧会静默失败（曾因权限位丢失导致全部生成失败）。
