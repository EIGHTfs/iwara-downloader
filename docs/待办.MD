## 封面状态机

当前封面生成逻辑：视频文件不存在 → 不生成；存在 → 抽帧覆盖。

**待实现：引入状态机解耦视频状态与封面状态**

| 状态 | 取值 |
| --- | --- |
| 视频状态 | `pending` → `transcoding` → `available` / `unavailable`（源文件丢失） |
| 封面状态 | `empty` → `generating` → `done` / `failed` |

生成条件：视频状态为 `available` 且封面状态不为 `done`。

收益：

- 错误封面不再占位（封面已完成但视频不可用时不再生成）
- 视频源恢复后自动触发重新生成
- 避免每次播放都重复抽帧
