🔄 自动更新

服务端代码自动更新 + 优雅重启：开发机推送代码后，服务端自动拉取并重启，无需手动同步。
三种模式的区别：
· 文件监控（watch）—— 监控本机 server/ 目录的文件变更，改完即重启；不轮询、不联网、无间隔，适合直接在本机改代码。
· 定时 git pull—— 需本机有 .git 与远端拉取权限，按间隔执行 git pull，有变更才重启（本地命令，成本低）。
· 定时查 GitHub—— 本机不需要 .git，按间隔调 GitHub API 比对远端提交，有新提交才拉取（每次检查消耗 1 次 API 配额）。
间隔仅对后两种模式生效，默认 3600 秒（1 小时）；连续失败会按该值的 2 倍逐级退避、最多 3 次（1h→2h→4h→8h），任意一次成功立即恢复。想马上生效请用「🔍 立即检查」（手动检查不计入失败连击）。
github 模式的仓库/分支/Token 在 server/config.json 手改（githubRepo / githubBranch / githubToken；Token 仅私有仓库需要）。
