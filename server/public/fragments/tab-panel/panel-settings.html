下载路径与命名

直连后端填本机路径；Aria2 后端填 Aria2 所在机器上的路径。模板不要写 .mp4，保存时自动补扩展名。

必须含 {ID}：封面 <id>.jpg、json、视频文件都靠这个 id 对上。其它变量：{TITLE} 标题　{ALIAS} 作者显示名　{AUTHOR} 作者用户名　{QUALITY} 清晰度　{UPLOADTIME} 上传时间　{NOWTIME} 下载时间

模板里的 / 是目录分隔：写 {AUTHOR}/Iwara_-_{TITLE}_[{ID}] 即按作者分目录；不写 / 则直接存下载根目录。

✏️ 按模板重命名文件

只认 json/index 里的 id。预览后点确认执行（无弹窗）。目标已存在会失败，可对那一条点「强制执行」覆盖重复。

视频索引

总表 iwara-index.json：以视频 id 为键，只存作者名/用户名、标题、fileId、时长、tags、上传日。不算 hash。下载目录本机可写则写到那里；Aria2 远程路径写不了时写到服务数据目录。可导入别人 dump，或扫描下载目录 json。
